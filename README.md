\# CloudVault



Sistema híbrido de respaldo local y web usando Amazon S3.



\## Descripción



CloudVault permite respaldar archivos desde una carpeta local de Windows hacia Amazon S3, utilizando versionamiento para conservar versiones anteriores.



\## Servicios AWS utilizados



\- Amazon S3

\- S3 Versioning

\- IAM / AWS Academy credentials



\## Funcionalidades iniciales



\- Subir archivos a S3 desde Python.

\- Listar archivos almacenados en S3.

\- Descargar archivos desde S3.

\- Automatizar infraestructura con PowerShell.
